# RAKSAMESIN Heavy Equipment Marketplace

**Self-Initiated Portfolio Project**  
**Individual Project - Full-Stack Web Developer**  
**Laravel / PHP / MySQL / Tailwind CSS / JavaScript**

## SUMMARY

RAKSAMESIN is a web-based heavy equipment marketplace for browsing verified machinery units, submitting purchase inquiries, and tracking buyer leads from inquiry to deal.

## PROJECT TYPE

Self-initiated portfolio project based on a practical digital broker workflow for selling excavators, bulldozers, wheel loaders, and other project vehicles.

## MY ROLE

This is an INDIVIDUAL PROJECT. I designed the database, built the Laravel backend, created authentication and roles, designed the public interface, and connected inquiries to lead management.

## IMPACT

The project turns scattered sales communication into one structured workflow for units, buyer leads, inspection schedules, and quotations.

## WHAT I LEARNED

I learned to map a high-value sales process into database relationships, secure authentication, role permissions, audit logs, file handling, and responsive UI.
