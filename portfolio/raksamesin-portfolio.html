Project 5

RAKSAMESIN Heavy Equipment Marketplace

Self-Initiated Portfolio Project
Individual Project - Full-Stack Web Developer
Laravel / PHP / MySQL / Tailwind CSS / JavaScript

Summary

RAKSAMESIN is a web-based heavy equipment marketplace designed to help buyers browse verified machinery units and submit purchase inquiries. The system supports vehicle listings, buyer leads, inspection requests, quotations, role-based access, Google login, and an admin workflow for managing the sales process from inquiry to deal.

Project Type

Self-initiated portfolio project developed from a practical business case: a digital broker platform for selling heavy equipment such as excavators, bulldozers, wheel loaders, and other project vehicles.

My Role

This is an INDIVIDUAL PROJECT. I worked as the full-stack developer, designing the database schema, building the Laravel backend, creating authentication and role-based access, implementing the public marketplace interface with Blade and Tailwind CSS, and connecting inquiry forms to a lead management workflow.

Impact

The project turns a manual heavy-equipment sales process into a structured digital workflow. Buyers can inspect unit information before contacting sales, while the admin side centralizes unit data, lead status, inspection scheduling, and quotation preparation. This reduces scattered communication and makes the path from catalog browsing to sales follow-up easier to track.

What I Learned

I learned how to translate a high-value sales workflow into a web application with clear data relationships, secure authentication, role permissions, audit logging, file handling, and responsive UI design. I also learned how to prepare a Laravel project for GitHub, screenshots, documentation, and future deployment.
